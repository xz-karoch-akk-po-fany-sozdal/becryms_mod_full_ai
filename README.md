# Backrooms / Закулисье (Fabric 1.20.1) — 15 этажей

Объединённая версия: сведены вместе идеи трёх разных набросков мода про Бэкрумс (один делал
упор на существ с эффектами-болезнями, другой — на «находки» и расходники, третий — на алтарь,
прогрессию и связку с Upgrader items) плюс мой собственный исходный мод на 6 уровней. Итог —
**15 этажей** в одном моде. **Ни один этаж не требует побеждать финального босса** — везде можно
просто прийти, осмотреться, забрать находки и уйти через Миндальную воду или Стабилизатор.

Работает сам по себе. Если установлен мод болезней (Disabilities или Handicap), Алтарь умеет
снимать болезнь, а некоторые существа дают её при ударе. Если в момент убийства существа или
использования Алтаря в руке у тебя предмет из мода Upgrader items (точный id не известен, ищется
по подстроке "upgrader" в id), добыча чуть лучше, а цена Алтаря вдвое ниже. Upgrader не обязателен.

**Важно:** я собрал этот мод вслепую, без доступа к серверам Fabric/Minecraft и без возможности
запустить игру. Все Java-файлы проверены на валидность JSON и на грубые синтаксические ошибки
(пропущенные скобки, точки с запятой), но точные сигнатуры API Minecraft 1.20.1 (особенно у
кастомных существ и их моделей) я подтвердить не могу — при сборке не исключены ошибки компиляции.
Текстуры мобов нарисованы по памяти об UV-развёртках ванильных моделей (паук/зомби/блэйз) и могут
лечь криво — это не критично, просто может выглядеть неаккуратно. Присылай ошибки сборки или
скриншоты — поправлю.

## 15 этажей

### Шесть этажей со своим существом (ядро мода)
| Этаж | Существо | Особенность |
|---|---|---|
| Бассейны («Не плескайся», по мотивам DON'T SPLASH) | **Сплэшер** | слепой, сидит в воде; если ты двигаешься в воде (а не стоишь неподвижно) — это «всплеск», ближайший Сплэшер бросается на тебя |
| Level 0 | **Гудящий** | медленный жёлтый коридорный житель |
| Level !!! | **Охотник** | быстрый, никогда не теряет цель, бьёт больно |
| Level Fun (цирк) | **Весельчак** | почти не бьёт, зато ворует предмет из инвентаря и путает тошнотой |
| Электростанция | **Статик** | летает, бьёт разрядом (медленность + усталость вместо урона) |
| Тьма | **Безликий во Тьме** | редкий, раз в ~8 секунд «взгляд» — слепота и тошнота всем рядом |

### Пять этажей-находок (идея с «трофеями» и расходниками)
| Этаж | Находка | Для чего |
|---|---|---|
| Жёлтый архив | Жёлтая плесень | сырьё для Upgrader/валюта |
| Город без окон | Кассета с помехами | сырьё для Upgrader/валюта |
| Затопленный атриум | Проба из бассейна | сырьё для Upgrader/валюта (этаж придётся проплыть) |
| Холодный реактор | Охлаждающий элемент | держи в руке на самом Холодном реакторе, чтобы не мёрзнуть |
| Красный карантин | Лиминальное ядро | редкая находка, всего одна на этаж |

### Четыре этажа-синдрома (идея про временные «болезни» от самого места)
| Этаж | Синдром | Эффект, пока ты там |
|---|---|---|
| Архив Паранойи | Паранойя | иногда тошнота и слабость, шёпот и звуки паука |
| Палата Глухоты | Глухота | постоянная медленность, гаснущий звук |
| Зал Некроза | — | если бежать (Sprint) — суставы «ломаются», урон и хруст скелета |
| Лабиринт Вентиляции | — | воздух кончается, как под водой; задохнёшься — получишь урон |

Синдромы «цепляются» на одежду — на самом этаже держатся на максимуме, после ухода слабеют
~90 секунд и проходят сами, либо снимаются сразу Стабилизатором.

Все 15 этажей строятся автоматически (простые процедурные комнаты/лабиринты), когда их измерение
открывается впервые — ничего вручную готовить не нужно.

## Предметы
- **15 Трещин** (по блоку на этаж) — ставь и жми ПКМ, чтобы телепортироваться.
- **Миндальная вода** — глоток возвращает туда, откуда ты вошёл в Закулисье (в памяти сервера,
  не переживает перезапуск сервера). Расходуется.
- **Стабилизатор** — снимает текущий синдром, не телепортирует. Крафтится.
- **Алтарь Закулисья** (блок) — ПКМ снимает случайную болезнь мода Disabilities/Handicap за 2
  изумруда (1 — если в руке предмет Upgrader). Без установленного мода болезней просто откажет.
- 5 находок (плесень, кассета, проба, охлаждающий элемент, ядро) — лут на своих этажах.
- 6 яиц призыва существ — для теста в творческом режиме.
- Обрывок записки — предмет-лор, без функции.

## Как собрать .jar через GitHub Actions (ничего не ставить на компьютер)
1. На github.com: **New repository**, любое имя, **Create repository**.
2. На странице пустого репозитория: **Add file → Upload files**, перетащи **содержимое** папки
   `backrooms-mod` (сами файлы и папки `src`, `.github` и т.д., а не папку целиком).
3. **Commit changes**.
4. Вкладка **Actions** → разреши workflow, если спросит → если сборка не началась сама, слева
   **build** → **Run workflow**.
5. Подожди 2-5 минут. Зелёная галочка — открой запуск, внизу **Artifacts → backrooms-jar**, скачай.
6. Распакуй zip, `backrooms-2.0.0.jar` → в `.minecraft/mods` вместе с Fabric Loader и Fabric API.

Если сборка красная — открой её, разверни шаг `Build mod`, пришли мне текст ошибки.

### Локально (если есть Java 17 и Gradle)
```
gradle build
```
Результат: `build/libs/backrooms-2.0.0.jar`.
